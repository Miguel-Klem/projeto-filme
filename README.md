## 🎯 Objetivo do Projeto
Criar uma página web em HTML5 aplicando os conceitos fundamentais de desenvolvimento web aprendidos em aula, organizando estruturadamente informações, mídias e links sobre o filme *Donnie Darko*.

## 🛠️ Tecnologias Utilizadas
* **Gemini:** Estruturação do README.md 
* **VS Code:** Editor de código-fonte utilizado para o desenvolvimento.
* **Git & GitHub:** Controle de versão e hospedagem do repositório do projeto.

## 📌 Breve Descrição da Página Desenvolvida
A página apresenta uma ficha técnica e resumo do filme **Donnie Darko**, estruturada da seguinte forma:

* **Título da Página & Cabeçalho (`<title>` e `<h1>`):** Exibe o nome do filme no topo da aba e no cabeçalho principal.
* **Imagem Promocional (`<img>`):** Exibe o pôster/imagem do filme armazenado localmente na pasta `img/`.
* **Ficha Técnica (`<h2>`):** Apresenta informações organizadas sobre:
  * **Ano de Produção:** 2001
  * **Diretor:** Richard Kelly
  * **Duração:** 113 min
  * **Classificação:** 14 anos
  * **Gênero:** Ficção Científica / Drama / Suspense
  * **País de Origem:** Estados Unidos
* **Sinopse (`<p>`):** Descreve a história do jovem Donnie Darko, suas visões com um coelho gigante enigmático chamado Frank e o mistério sobre a contagem regressiva para o fim do mundo.
* **Mais Informações (`<a>`):** Link externo configurado com `target="_blank"` direcionando para uma página detalhada sobre a obra.
